# Optimized phone previews for the labeling helper

## Summary

The labeling helper (DAT-07) is now practical over a phone connection, per the lead's request: it serves an optimized preview instead of the 1024 px analysis JPEG, and it can bind beyond localhost so the owner can label at http://strixhalo:<port>/ from a phone. Measured over all 440 sample photos, previews average 42 KB against 149 KB for the analysis images (18.8 MB vs 67.3 MB for the full queue), are generated once and cached on disk, and are served with immutable cache headers plus ETag/304 support so repeat views cost no transfer. Previews for all 440 were pre-generated locally, so phone labeling has no per-photo generation wait. hipEngine DE-2.1 was skipped by lead decision (Q5_0 loader gap plus a nearly full disk on the gfx1151 box; see task notes in this session, not a product blocker).

## Changes

- `crumbs/label_server.py`: `ensure_preview()` renders a 640 px long-edge, quality-68, metadata-stripped JPEG via ImageMagick into the ignored `data/crumbs/previews/` cache (content-hash named); falls back to the analysis image if generation fails. `/img/` now serves the preview with `Cache-Control: public, max-age=31536000, immutable` and ETag/If-None-Match handling. Page gained a mobile viewport meta tag.
- `crumbs/cli.py`: `crumbs label --host` (default 127.0.0.1; use 0.0.0.0 for phone access via the machine's hostname).
- Local only (not repo state): `data/crumbs/previews/` pre-generated for all 440 photos.

## Validation

- Throwaway data dir on port 18766 (18765 was already occupied by an unrelated local service): page loads with viewport; `/api/next` returns the priority queue head; `/img/29.jpg` returned the 640x480 preview at 55,866 bytes vs the 207,453-byte analysis original, with the immutable Cache-Control and ETag headers; conditional GET returned 304; POST `/api/label` wrote the label row into the test DB only — the real DB still showed 0 labels afterwards.
- Full preview generation for the real corpus: 440 previews in 10 s; mean 42 KB, median 41 KB (analysis mean 149 KB).
- `python3 -m py_compile crumbs/label_server.py crumbs/cli.py` passes.
