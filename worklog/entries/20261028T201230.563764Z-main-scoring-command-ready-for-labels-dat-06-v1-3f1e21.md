# Scoring command ready for labels (DAT-06 v1)

## Summary

DAT-06 v1 exists before the labels do, deliberately: `crumbs score` joins the append-only user labels to the latest classifications and reports category confusion, accuracy overall and when-decided, explicit abstention counts (model 'unknown' is never silently an error class), and dish-label recall against extractions, as JSON for report generation. Run today it correctly reports the empty state and what is needed (~50–100 labels over the food + unknown slice via `crumbs label`). No metric is claimed until labels exist — that discipline is the point of building the scorer first.

## Changes

- `crumbs/score.py`: label/classification join, confusion + abstention accounting, dish recall; `crumbs/cli.py`: `score` subcommand.

## Validation

- `crumbs score` on the current store returns the no-labels state verbatim (labeled_media 0) instead of an empty table or an error.
