# Add lightweight globe cache and streaming PMTiles mode

## Summary

Closed the local globe's 'missing planet' gap two ways in `spike/map-globe/`. (1) Lightweight globe cache: `tools/fetch-tiles.sh` now also extracts a whole-planet z0–5 archive (15 MB; measured z≤6 = 45 MB, z≤7 = 190 MB, so z5 is the sweet spot) and the local style carries two PMTiles sources with a zoom-gated layer handoff (backdrop z<7, regional detail z≥6) — the offline globe now shows the full Earth while street detail still comes only from the regional extracts. (2) Streaming mode: a new switcher style points the `pmtiles` protocol straight at a remote planet archive and transfers only viewed tiles (8 range requests for the initial globe) — with the finding that `build.protomaps.com` sends no CORS headers (browsers cannot stream from it) while the Source Cooperative mirror does. Streaming is documented as online/not-private and stays opt-in; fully-local remains the default.

## Changes

- `spike/map-globe/tools/fetch-tiles.sh`: adds the `--maxzoom=5` whole-planet extract to `public/tiles/protomaps-globe.pmtiles` (still git-ignored) and reports its size.
- `spike/map-globe/src/main.js`: local style rebuilt as a two-source style (`protomaps-globe` + `protomaps`) with per-layer zoom gating (`-globe` suffixed ids, backdrop maxzoom 7, detail minzoom 6); new `STREAM_STYLE` against `pmtiles://https://data.source.coop/protomaps/openstreetmap/v4.pmtiles` with the CORS finding commented. `index.html`: streaming option added, local option relabeled. `README.md`: globe-cache row, handoff explanation, streaming section with the CORS/privacy findings.

## Validation

- `sh tools/fetch-tiles.sh` (incremental): globe archive 15 MB in place; `npm run build` passes.
- Offline re-test (all non-localhost requests aborted, headless Chromium, SwiftShader): 0 external requests, 74 same-origin PMTiles range requests, globe screenshot now shows the complete Earth (continents/oceans/labels) and the Kyoto street view is unchanged (FPS readings in this software-GL setup varied 22–61 across runs/views; no page errors).
- Streaming test (online): selecting the streamed style rendered the planet basemap with 8 range requests to the mirror and no page errors; the direct `build.protomaps.com` attempt rendered nothing and header checks confirmed the missing `Access-Control-Allow-Origin`, which is why the mirror is used.
