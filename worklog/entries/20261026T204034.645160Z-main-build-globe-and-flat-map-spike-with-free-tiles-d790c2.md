# Build globe and flat-map spike with free tiles

## Summary

Built and exercised `spike/map-globe/`: a Vite + MapLibre GL JS 5.24 web spike with a native globe/Mercator projection toggle, clustered synthetic photos, capped DOM thumbnail markers per selected trip, dashed per-trip trails plus an interpolated progress trail with play/scrub playback, an FPS meter, and a 5,000-photo stress mode. Researched free tile sources (OpenFreeMap, CARTO Basemaps, OSM tile policy, Protomaps/PMTiles self-hosting, OpenMapTiles self-host) with terms in the spike README; recommendation closes PLAN R6 at spike level: MapLibre for both views, clustered-GeoJSON + capped-thumb split for performance, OpenFreeMap default, CARTO alternate, PMTiles regional extracts as the privacy-clean product default. PLAN.md's R6 row now points at the spike. This is the first code unit in the repo; data is fully synthetic and no personal data was used.

## Changes

- Added `spike/map-globe/` (`package.json`, `package-lock.json`, `index.html`, `src/main.js`, `src/data.js`, `src/style.css`, `README.md`): one map with `setProjection` globe/flat toggle and `setSky` atmosphere, style switcher (OpenFreeMap Liberty/Positron, CARTO Voyager, OSM raster fallback), trip filter with fitBounds, photo list + card, timeline scrubber/player, deterministic synthetic dataset (126 photos, 3 trips) and +5,000 stress generator.
- `PLAN.md`: R6 row records the spike outcome and recommendation.

## Validation

- `npm run build` passes (JS ≈1.07 MB / 289 KB gzip, CSS ≈72 KB / 10.6 KB gzip, essentially MapLibre).
- Headless Chromium (system chromium via Playwright, SwiftShader GL) against `vite preview`: globe confirmed via `getProjection()` = `globe` and screenshot (sphere + atmosphere, cluster counts); scripted flow — projection toggle, Kyoto trip select with fitBounds, play/pause trail stepping, photo card contents, +5,000 stress add (5,126 total) — all pass with no page errors; FPS ≈60 in the test's frame loop in all views including stress with DOM thumbs correctly suppressed above the 300 cap. Fixed during testing: cluster-count layer font pinned to `Noto Sans Bold` (OpenFreeMap glyph stacks), duplicate source-add on style reload, stats line DOM-thumb count. Remaining non-fatal MapLibre style warnings on projection/style switches are noted in the spike README.
