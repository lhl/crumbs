# Wire real corpus into globe spike (PWA-05/06 against real data)

## Summary

The map/globe spike now renders the real reconstructed corpus, fully offline: `crumbs export-spike` emits 399 GPS photo points + 228 visits + 14 trips from the evidence store, and the spike loads them (real analysis-image thumbnails, Glimmer category on each card, per-trip filter/trails/list/playback) whenever `public/crumbs-data.json` is present, falling back to the synthetic set when it is not. Verified in headless Chromium with all non-localhost requests blocked: 0 external requests, no page errors, real clusters on the offline globe (Japan/home clusters visible), a real menu-board photo card classified `food`, 61 fps under software GL. Both the export and the 62 MB of thumbnails are git-ignored personal data (`git check-ignore` verified; nothing personal committed). Visible limitation, same root cause as the REC-01 note: sample sparsity over-merges trips (one 'trip' spans multiple cities), so trip bounds can span a continent — the mechanics are proven, the segmentation quality awaits the full-corpus import and labels.
