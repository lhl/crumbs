# Ask engine v1 over the local index (AGT)

## Summary

AGT v1 answers the demo query families by composing the local index, with every claim assembled from records and evidence ids attached: (A) 'what did I have at <place>' — visits where the place is a candidate, with dishes from their extractions, worded as candidate-not-confirmed after a wording audit caught the first version overstating GPS linkage; (B) anchor + window recall ('what was the dashi restaurant near Arashiyama in October 2019?' → the 2019-10-09 visit with its four ranked restaurant candidates); (C) 'last time I was here' with current coordinates → nearest past visits with dishes; (D) keyword fallback over extraction text; anything else returns a designed unknown. Exposed as `crumbs ask` and `GET /v1/ask` (which can resolve `near=current` from the bridge's device-posted location). This is a deterministic intent parser over the AGT-01-shaped tools, not yet a Glimmer tool-calling loop (AGT-02) and not yet compared against plain search (AGT-03/R13) — both remain open and the agentic claim stays unmade until R13 is measured.

## Changes

- `crumbs/ask.py`: intent families A–D, place-name matching against the registry, public area anchors, month/year window parsing, records-only answer assembly with evidence refs.
- `crumbs/cli.py`: `ask` subcommand; `crumbs/api.py`: `/v1/ask` endpoint with bridge current-location resolution.

## Validation

- Four live queries against the real store, all behaving as designed: anchor/week (answered with visit 187 + ranked candidates), place-dishes (answered, candidate wording), 'Noma' (unknown — not in our history, correctly), last-time-here at the Arashiyama coordinates (answered with the visit and its seen dishes).
- `/v1/ask` through the token-gated API returns the same structured answer + evidence.

## Next

- Golden queries (DAT-04) turn these families into the R13 comparison: this engine vs plain embedding search, same questions. A Glimmer tool-calling front-end (AGT-02) can then replace the parser without changing tools or the answer contract.
