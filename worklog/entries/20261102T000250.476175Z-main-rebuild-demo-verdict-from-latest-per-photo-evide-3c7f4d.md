# Rebuild demo verdict from latest per-photo evidence

## Summary

The demo manifest no longer counts every model/version as a separate photo or repeats the obsolete claim that no user labels exist. A strong place candidate is eligible for the signage demo beat only when the same candidate actually has text-match evidence. The current store still does not pass the end-to-end demo sufficiency check; extraction and reconciliation remain active work.

## Changes

- Category totals use one latest classification per media item, matching map export semantics, and include unclassified photos.
- Label gaps count missing human category labels rather than treating model-origin labels as scoring ground truth.
- Text-backed strong candidates require matching `signage-text` evidence; proximity/dwell scoring alone cannot populate that beat. No candidate is renamed confirmed.
- Gap wording uses current visit/trip counts and preserves the owner-consent/public-video blocker.
- Added two synthetic manifest tests. Restored and validated the pre-compaction changes to `crumbs/demo.py` as part of this unit.
