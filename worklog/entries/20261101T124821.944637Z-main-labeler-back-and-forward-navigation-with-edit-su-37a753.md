# Labeler back and forward navigation with edit support

## Summary

The labeler now has real back/forward navigation at the lead's request: ArrowRight (or Skip / `s`) advances, ArrowLeft (or the new Back button) returns to previously viewed photos, and going back to an already-labeled photo shows the owner's own labels prefilled for correction (saving appends a new pass, which scoring already treats as authoritative). This also fixes a latent bug: Skip previously re-fetched the same unlabeled queue head and appeared to do nothing. The real label server was restarted with the new build; labeling progress was preserved.

## Changes

- `crumbs/label_server.py` server: `/api/next` accepts `?exclude=<media_ids>` so forward navigation never re-shows skipped items; new `/api/item/<media_id>` returns any photo with its latest user labeling pass (`user_category`, `user_evidence`); item-building and counts factored into `_build_item`/`_counts` shared by both endpoints.
- Client: a visited-history stack drives Back/Forward; `advance()` walks the stack before fetching new items; `show()` prefills user labels when present (meta line notes 'your label: ... (saving overwrites)'); ArrowLeft/ArrowRight handlers and a Back button added.
