# Glimmer-DE raw reads over 440 scored against owner labels

## Summary

The no-training Glimmer-DE raw read (assistant-prefill scaffold, letter distribution from logprobs, 640 px images) ran over all 440 labeled photos in 1170 s (2.69 s/read) and scored against the owner labels: **food F1 0.877** (recall 57/61, precision 57/69) — between PE (0.53-0.55) and the generative Glimmer read (0.976), and effectively tied with DE-2.1 (0.898 API / 0.893 local) at roughly a third of DE-local's per-question cost and a seventh of the generative read's 19.4 s. Full-category accuracy with the human 'other' mapped to the model's 'unknown' is 0.814, and agreement with the generative read is 0.818 — both inflated for the non-food categories because those labels mostly confirm the generative model's own suggestions; the food slice, which the owner verified individually, is the unbiased comparison. Answer mass behaves as AnyJev's diagnostic predicts: accuracy rises monotonically with the mass floor (coverage 100% → 0.814; mass ≥ 0.3 → 56.8% coverage at 0.888; mass ≥ 0.5 → 40.2% coverage at 0.927), so the production shape is a mass-gated read with generative escalation for the remainder, not a bare read. Verdict: worth building as the bulk category classifier in a `crumbs` stage; DE-2.1 remains a comparator only (lead decision), and LoRA training (the original GDE plan) is now a quality upgrade to justify against these numbers, not a prerequisite.

## Validation

- 440/440 reads, 0 errors; wall 1170 s for the main batch (mean 2.69 s/read, 496 prompt tokens at 640 px vs 1131 at 1024 px).
- Food slice: recall 57/61 (misses: 3 sightseeing, 1 trip), precision 57/69, F1 0.877.
- Answer mass: mean 0.434, median 0.371; 37 reads below 0.1 and 190 below 0.3 — the mass floor is doing real work in the gated operating points quoted in the summary.
- Confusion highlights: trip is the leakiest true category (89/121 correct; 21 read as unknown, 12 sightseeing read as trip); personal reads well (48/60).
