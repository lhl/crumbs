# Local DE-2.1 GGUF on gfx1151 box completes classifier comparison

## Summary

DE-2.1 now runs locally on the third Strix Halo box (`gfx1151`, hostname; the other two are `strixhalo` and `zbook`): the Q4_K_M GGUF copied from zbook plus the base Gemma 4 F16 mmproj (DE's vision encoder is the untrained base model, so the base projector is the matching one), served by the freshly built latest llama.cpp (build 12032) at `gfx1151:18081`. Over the same 440 photos and 9 questions used for the API arm, the local model agrees with the hosted BF16 API on category 92.5% of the time (mean probability total-variation distance 0.075), and with Glimmer 66.1% (API arm: 68.0%) — so the Q4_K_M quantization plus llama.cpp rendering costs little against the API reference. Local speed is 8.47 s/photo mean for all 9 questions sequential on one server slot (~0.94 s per read, dominated by re-encoding the image per question); the server is still running on gfx1151. This completes the classifier comparison from worklog 20261101T095719: PE-L remains the speed outlier (0.138 s/photo, 44.3% Glimmer agreement), DE the closest to Glimmer at ~30-60x PE-L's cost depending on arm, and true accuracy remains undetermined until hand labels exist.
