# Add DISCOVERY model test plan and expand brainstorm use cases

## Summary

Added DISCOVERY.md as the pre-plan gate: a verified catalog of Meta models relevant to Crumbs (Muse Spark 1.3, Wonder, Glimmer, Spark Open, SAM 3.1, DINOv3, Voice Transcribe, Image, Code) mapped to Crumbs' five perception/reasoning jobs, plus seven ordered experiments (E0 golden corpus through E7 stretch probes) with metrics, pass/kill criteria, and the decisions each feeds. Key findings: DINOv3 is a strong local embedding/classification-head candidate but its license is the DINOv3 License (not Apache) and the hackathon open-weight bonus names only Glimmer/Spark Open, so DINOv3 cannot be the sole Meta-model story; SAM 3.1 is API-only and earns its place only via an ablation; local multimodal Glimmer on the Strix Halo box is unproven (no verified AMD platform, no ROCm vLLM image) with llama.cpp GGUF + vision projector as the promising path. BRAINSTORMING.md gained the practical use cases the lead specified: in-the-moment recommendation/sharing, reordering what was good, geospatial recall of prior enjoyment/orders, sightseeing/trip/personal/food classification as a core local feature, and an evidence-linked factual taste profile with photo-frequency bias guardrails.
