# Sample 2019 photo corpus into ignored data dir (DAT-01 start)

## Summary

DAT-01 started: sampled the lead's local 2019 iCloud Photos tree (YYYY/MM/DD layout, 11 month folders — no December folder present; ~9,300 stills plus ~8,000 video/live-photo companions in source) into the ignored `data/sample-2019/` at 40 photos/month = 440 photos (863 MB). Sampling is systematic over each month's EXIF-chronological order so trip bursts and quiet weeks are represented in proportion; videos are excluded. EXIF reads cleanly and locally via exiftool: 413/440 sampled photos carry DateTimeOriginal and 399/440 carry GPS — coverage high enough that E0 labeling and IMP-01/IMP-03 have real timestamps/timezones/GPS to work with. Composition: 391 HEIC, 27 PNG, 22 JPG; mostly two iPhone models plus a few drone/360 frames. `.gitignore` already covered `/data/` (verified with `git check-ignore` on copied files); nothing personal is committed — only the sampler script and this entry. This is a working sample, not yet the DAT-01 corpus: no location export is paired yet, no labels exist, and no public-demo subset has been chosen or reviewed.

## Changes

- `scripts/sample_corpus.py` (new): generic YYYY/MM/DD sampler — batch exiftool JSON read (DateTimeOriginal/CreateDate, GPS, model, dimensions), chronological systematic sample per month, mirrors MM/DD into the destination, writes `manifest.csv` + `summary.json` next to the copies. Takes `--source/--dest/--per-month`; no personal paths in code.
- Local only (not committed): `data/sample-2019/` with 440 photos + manifest + summary. Source paths and GPS exist only in that ignored manifest.

## Validation

- Sampler run: per-month source stills ranged 71–2,021; 40 sampled per month, 440 total; copied tree verified (442 files incl. manifest/summary, 863 MB).
- EXIF spot check: a copied HEIC's DateTimeOriginal matches its manifest row exactly.
- `git check-ignore -v` confirms copied files and manifest are ignored via `/data/`; `git status` shows only the new script before commit.
