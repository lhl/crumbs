# Local-only processing is the core architecture

## Summary

Lead decision recorded and propagated: Crumbs ships local-only — all image classification, embedding, evidence extraction, visit reconstruction, and agentic retrieval run on local open models (Muse Glimmer + DINOv3); no photo or location record goes to a cloud model API. Muse Spark/Wonder/Spark Open (hosted) and SAM 3.1 are excluded from the shipped pipeline (cloud models may serve only as disclosed development oracles on the consented demo subset); optional Muse Voice Transcribe is the sole possible exception, off by default and audio-only, with exact privacy wording prescribed. Hardware basis changed accordingly: the lead has RTX PRO 6000 (96 GB) cards — a vendor-verified single-card Glimmer bf16 configuration under SGLang, and within vLLM's ≈72 GB serving requirement — so CUDA/vLLM/SGLang/PyTorch/ONNX is the primary target and the Strix Halo box becomes a portability test (llama.cpp GGUF + vision projector) instead of the gate for the local story.
