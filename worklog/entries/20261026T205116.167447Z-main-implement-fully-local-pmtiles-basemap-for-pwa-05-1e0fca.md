# Implement fully-local PMTiles basemap for PWA-05

## Summary

Implemented the tile half of PWA-05 in `spike/map-globe/`: a fully-local Protomaps/PMTiles basemap, now the default style. `tools/fetch-tiles.sh` (pinned go-pmtiles 1.28.2) extracts the Kyoto/Taipei/Lisbon demo regions from the Protomaps daily planet build into one 40 MB PMTiles archive plus 15 MB of glyph fonts and 180 KB of sprites — all git-ignored, fetched in ~16 s via HTTP range requests (the ~120 GB planet file is never downloaded). The app generates the style in code with `@protomaps/basemaps` and reads tiles through the `pmtiles` JS protocol against the same-origin archive. Headless offline test with all non-localhost requests blocked: zero external requests, Kyoto rendered fully (streets, Japanese labels, POIs), globe/trails/playback working. PLAN R6 and IMPLEMENTATION PWA-05 now record this; PWA-05's product flow (visit pins/filters against real data) remains open.

## Changes

- `spike/map-globe/tools/fetch-tiles.sh` + `tools/demo-regions.geojson`: pinned CLI download, `--region` MultiPolygon extract (`--maxzoom=15`, `PROTOMAPS_BUILD` override), fonts/sprites extraction from the `protomaps/basemaps-assets` tarball.
- `spike/map-globe/src/main.js`: registers the `pmtiles` protocol, builds the local style (local glyphs/sprite URLs, `namedFlavor('light')`, `lang:'en'`), makes it the default, adds a header indicator when the archive is missing. `index.html`: local style preselected, tile-status element. Dependencies added: `pmtiles`, `@protomaps/basemaps`.
- `spike/map-globe/.gitignore`: `public/tiles|fonts|sprites`, `tools/bin/`, `dist/`, `node_modules/` — no tile data committed (verified with `git check-ignore`).
- `spike/map-globe/README.md`: fully-local mode section (sources, measured sizes, offline verification). `PLAN.md` R6 and `IMPLEMENTATION.md` PWA-05 annotated.

## Validation

- `sh tools/fetch-tiles.sh` from clean state: 41 MB archive written in ~16 s (110 range requests), fonts/sprites in place; `npm run build` passes and copies `public/` into `dist/`.
- Headless Chromium (`vite preview`, SwiftShader GL) with a Playwright route handler aborting every non-`127.0.0.1:4173` request: tile-status ✓, `getProjection()` = `globe`, 35 same-origin PMTiles range requests, **0 external requests attempted**, no page errors; screenshots confirm Kyoto street-level detail with labels/POIs plus photo thumbs and the progress trail; FPS ≈61 globe / ≈41 in the dense Kyoto DOM-thumb view under software GL (earlier hosted-style runs were ≈60; real GPUs expected faster). Areas outside the three extracts are intentionally blank in local mode.
